## Variant: Document Editor

### Design stance
Spacious, single-column, document-style. Treats the lands list like a Notion database or Linear issue list — minimal chrome, content breathes.

### Key choices
- **Layout:** Centered 1200px container, single column. Cover with icon + title + description, no sidebar.
- **Typography:** Inter 400–700, larger H1 (4xl), generous line-height
- **Color:** Warm-neutral canvas `#fafaf7`, white cards with `#f0eeea` borders, stone-warm secondary text
- **Elevation:** No shadows — borders only. More like reading than tooling
- **KPI:** Inline metadata strip, not tiles
- **Toolbar:** Search + dropdowns as outlined buttons, view mode as a small pill

### Trade-offs
- Strong at: Readability, premium feel, executive-friendly, writing-focused
- Weak at: Power-user features (sidebar filters, quick KPI clicks)
- Best for: Executives, investors, anyone scanning the catalog
