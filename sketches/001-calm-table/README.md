## Variant: Calm Table

### Design stance
Calm, monospace-friendly, content-first. The data table is the hero; the chrome stays out of the way.

### Key choices
- **Layout:** Slim top nav, three sectioned header strips (title / KPIs / filters+table), 280px sticky sidebar with sectioned white cards
- **Typography:** Inter 400–700, charcoal `#242424` headings, gray-500 secondary
- **Color:** Pure white canvas, gray-100 borders, one indigo accent (`#533afd`); tinted status pills (emerald-50 / cyan-50 / orange-50) for color
- **Elevation:** Cal.com's multi-layered shadow stack (ring 1px + soft 4px + contact 1px) — no solid borders
- **KPI:** Borderless inline strip (no tiles), 2x4 simple metrics

### Trade-offs
- Strong at: Scan-ability, calm reading, professional data density
- Weak at: Visual differentiation, wow-factor, premium feel
- Best for: Power users, accountants, ops managers who live in the data
